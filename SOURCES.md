# Sources — what is known about the candidate projects, and how it is known

Rule: every fact names the page it came from and how it was read. In this session no project page
could be opened (every fetch failed at name resolution; the container's proxy denies the hosts), so
each fact below was read from a **web-search snippet** of the page named, not from the page itself.
Snippets are quoted by search engines and can be truncated or stale: each fact is **unverified until
the page is read**, and none has been used as a dimension in the model. Image hosts are unreachable;
no drawing has been seen.

**Concern for candidate selection (owner's call):** Section Haus is published as a *renovation* of a
1980 house with precast pillars and an inverted slab. FI-CONC-006 aims at simulating the construction
of a reinforced-concrete building from the ground up; a renovation's drawings may show existing
structure more than new work. The alternatives below are new builds.
